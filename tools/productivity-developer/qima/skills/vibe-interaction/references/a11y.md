# 无障碍 a11y 专业规范(vibe-interaction reference)

> 本文件承载 `SKILL.md`「交互专业深化 · A 无障碍」的完整规范。`vibe-interaction` 以 **WCAG 2.1 AA** 为**心智底线**(不是事后补丁),对**所有产品**强制生效。逐元素只标差异,全局基线一处声明(见末节 A.6)。

## 一、四类专业规范

### 1. 可感知(对比度)
- 正文文本对比度 **≥ 4.5:1**;大字号(**≥ 18.66px 粗体或 24px**)与图形/状态色 **≥ 3:1**。
- **颜色不得作为唯一信息载体**:如「红=错误」必须**同时有图标 + 文案**。
- 对比度由 **shadcn 组件变体体系(套件铁律基线)** 的**语义化 token** 在 light / dark 两套主题下分别满足,**不在调用处临时染色**。

### 2. 可操作(键盘可达)
- 所有「呈现方式分类法 Taxonomy」(见 SKILL.md 正文同名节 / 本目录 `interaction-taxonomy.md`)触发的交互必须**纯键盘可达**——可 `Tab` 聚焦、`Enter`/`Space` 激活。
- 焦点态有清晰可见的 `focus-visible` ring(沿用 **shadcn 组件变体体系(套件铁律基线)** button 基线里的 `focus-visible:ring-2 focus-visible:ring-ring`,不依赖 `architecture.md` 已写),**禁止 `outline:none` 而无替代**。
- 触控目标 **≥ 44×44px**。

### 3. 焦点管理(进入 / 陷阱 / 归还)
- 打开 `modal` / `confirm` / `drawer` / `bottomsheet` 时焦点**移入容器**、容器内 `Tab` 循环(**焦点陷阱**),`ESC` 关闭。
- 关闭后焦点**归还到触发元素**(回到那个按钮的元素 ID),而非丢回 `<body>`。
- `Tab` 顺序遵循阅读顺序(**DOM 顺序 = 视觉顺序**),**禁用正数 `tabindex`**。

### 4. ARIA 与语义化
- **优先用语义化原生元素**(`<button>` / `<nav>` / `<main>` / `<dialog>`),原生不足时再补 ARIA。
- 表单控件必有**可编程关联的 label**(`<label for>` 或 `aria-labelledby`)。
- 校验错误用 `aria-invalid` + `aria-describedby` 指向错误文案。
- 状态色之外补 `role` / `aria-*` 语义。

## 二、Radix / shadcn 已内建什么 · 还需补什么

| shadcn / Radix 组件(承载的 taxonomy) | 已内建的 a11y | `interaction.md` 仍需显式补充 |
|---|---|---|
| `Dialog`(`modal`)/ `AlertDialog`(`confirm`) | 焦点锁定 + 焦点陷阱、`ESC` 关闭、`role="dialog"` + `aria-modal`、`aria-labelledby/aria-describedby`、关闭后焦点归还触发点、点遮罩关闭 | 标题/正文与 `aria-labelledby`/`aria-describedby` 的对应文案;`confirm` 默认焦点落「取消」(沿用 SKILL.md「模板 F · 权限门控矩阵 & 模板 G · 边界异常约定」的二次确认约定);危险主按钮用 Button `destructive` variant |
| `Sheet`(`drawer`)/ `Drawer` vaul(`bottomsheet`) | 同 Dialog 一族的焦点锁定 + `ESC` + aria | 关闭时若有未保存改动 → `confirm`(沿用 SKILL.md「完整示例」里 drawer 关闭未保存的处理);`side` 滑入方向 |
| `Popover` / `DropdownMenu`(`popover`) | 键盘可达、方向键在菜单项间移动、`ESC` 关闭、点外部关闭、`aria-expanded`、焦点回锚点 | tooltip 型 popover 不能仅靠 hover——须 `focus` 也能触发(键盘用户可达) |
| `Sonner`(`toast`) | 容器已是 `aria-live` 区域 | 明确语义级别:普通成功/信息用 `polite`,可恢复错误用 `polite` + 保留可操作焦点,**避免** `assertive` 滥用打断读屏 |
| `Accordion` / `Collapsible`(`inline-expand`) | `aria-expanded`、键盘展开/收起 | 展开后新内容的焦点与可达顺序 |
| 就地 `Input` + `Form`(`inline-edit`) | Radix 无专门原语 | **须补**:进入编辑态时焦点移入输入框、label 关联、`ESC` 取消归还原值、`Enter`/`blur` 保存、保存结果经 `aria-live` 播报 |

## 三、逐 taxonomy 的 a11y 要点(标注口径)

- `modal` / `drawer` → 焦点锁定 + `ESC` 关闭 + 关闭后焦点**归还触发元素 ID**。
- `confirm` → 同上,且**默认焦点落「取消」**,危险主按钮 `destructive`。
- `toast` → `aria-live="polite"`,**不抢焦点、不打断**当前操作。
- `popover` → 键盘可达(`focus` 即可触发,非仅 hover)、`ESC` 关闭、焦点回锚点(`aria-expanded` 随开合变化)。
- `inline-edit` → 标签关联 + 进入即聚焦 + `ESC` 取消 + 结果播报。
- `navigate` → 路由切换后焦点移到新页面主区/标题,供读屏宣告页面变更。

## 四、逐元素 a11y 标注模板

在 SKILL.md「模板 D · 可交互元素的交互规格」中,为**每个可交互元素**新增一行 a11y 标注(三要素:键盘 / aria / 焦点去向):

```markdown
- **a11y**:键盘=<Tab 可达 / Enter|Space 激活 / ESC 关闭>;
  aria=<role / aria-label|labelledby / aria-expanded|invalid|describedby / aria-live 级别>;
  焦点去向=<打开后焦点落在? 关闭后归还到哪个元素ID?>
```

## 五、全局 A.6 a11y 基线(一处声明,各页继承)

在 SKILL.md「模板 A · 全局信息架构」新增 **A.6 全局 a11y 基线**,逐元素只标差异:

- **跳转链接 skip-to-content**:页首提供「跳到主内容」隐藏链接,键盘第一个 `Tab` 可达。
- **`lang` 属性**:根 `<html lang="...">`,多语言页随切换更新。
- **全局 `focus-visible` ring token**:沿用 **shadcn 组件变体体系(套件铁律基线)** 的语义化 token,统一焦点环样式。
- **最小对比度与触控目标规约**:正文 ≥ 4.5:1、大字/图形/状态色 ≥ 3:1;触控目标 ≥ 44×44px。
- **读屏宣告策略**:`toast` 用 `aria-live="polite"`;路由切换后焦点移到新页主区/标题供读屏宣告。
