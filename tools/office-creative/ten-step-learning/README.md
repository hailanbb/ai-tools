# 十步学习法 (Ten-Step Learning)

基于 STORM 架构的深度自适应学习与知识图谱构建工具，通过十步递进式探索，帮助用户在 2 小时内快速掌握任意新主题，并生成交互式一页 HTML 速查卡片。

---

## 🛠️ 第一阶段：环境自检与前置依赖 (Doctor & Onboarding)

在使用「十步学习法」技能前，Agent 必须进行前置环境与依赖检测：

### 1. 依赖自检
* **真实联网检索依赖**：检查 Agent 是否具备 `web-access` 或类似联网搜索/内容提取能力（如 `search_web` / `read_url_content`）。
* **HTML 文件写入能力**：确保 Agent 能够向本地文件系统写入包含 CSS 和 JavaScript 的完整单文件 `.html` 页面。

### 2. 触发方式与初始化
* **触发关键词**：“十步学习法”、“STORM学习”、“学习 [主题]”、“帮我研究 [主题]”。
* **参数要求**：用户必须提供明确的“目标学习主题”或“领域关键词”。若未提供，Agent 必须提示用户输入。

---

## 🚀 第二阶段：核心执行工作流 (Workflow)

「十步学习法」严格遵循 STORM 架构的 10 步递进探索流程：

### 1. 步骤一览 (STORM 10-Step Loop)
1. **五视角调研**：从专家、新手、行业应用、历史演变、争议焦点 5 个维度并行检索。
2. **矛盾图谱构建**：识别该主题的核心争议点、权衡取舍（Trade-offs）与认知误区。
3. **2小时核心突破**：提炼最核心的 20% 原理（遵循 80/20 法则），建立知识主干。
4. **费曼循环校验**：用通俗浅显的语言解释复杂概念，检测认知死角。
5. **案例实战拆解**：结合 2-3 个真实世界应用场景进行深度分析。
6. **边界条件探索**：明确该知识/技术的适用范围与失效边界。
7. **工具链与生态地图**：梳理相关工具、框架及主流解决方案。
8. **前沿演进预测**：总结当前发展趋势与未来演进方向。
9. **一页速查卡片生成**：将上述全量知识重塑为独立且响应式的单文件 HTML。
10. **持续自学习建议**：提供延伸阅读路径与实践练习清单。

### 2. 产出物标准
* **格式**：单文件 HTML (`.html`)，内嵌完整 CSS 样式与交互脚本。
* **视觉与体验**：使用现代高对比度色调、自适应布局、具备高 Scannability（一目了然的可读性）。
